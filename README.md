# MyLink (마이링크)

나만의 링크를 관리하고 공유하는 마이링크 프로젝트 저장소입니다.

## 저장소 구조

```text
my-link/
├── mylink/              # 마이링크 Next.js 프론트엔드 애플리케이션
│   ├── src/             # 애플리케이션 소스 코드
│   ├── public/          # 정적 애셋
│   ├── package.json
│   └── tsconfig.json
├── LICENSE              # 라이선스 파일
└── README.md            # 저장소 안내 문서
```

## 시작하기

```bash
# mylink 폴더로 이동
cd mylink

# 개발 서버 실행
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)으로 접속하여 확인할 수 있습니다.
